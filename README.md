# Taller de Estructuras Condicionales en C#

## Información del aprendiz

- **Nombre:** Jeronimo Henao Sanchez
- **Programa de formación:** Análisis y Desarrollo de Software (ADSO)
- **Ficha:** 3412768
- **Institución:** SENA
- **Lenguaje de programación:** C#
- **Plataforma:** .NET

## Descripción del proyecto

Este repositorio contiene el desarrollo del taller de problemas de estructuras condicionales en C#. Está compuesto por 30 ejercicios independientes, organizados en una sola solución de .NET.

Cada ejercicio permite practicar el uso de condiciones, operadores, estructuras de selección y validaciones para resolver diferentes situaciones mediante programas de consola.

## Objetivo

Practicar y fortalecer los conocimientos básicos de programación en C#, aplicando estructuras condicionales para evaluar datos y mostrar resultados según las condiciones establecidas en cada problema.

## Tecnologías utilizadas

- C#
- .NET SDK
- Visual Studio Code
- Git y GitHub
- PowerShell

## Estructura del repositorio

Los ejercicios están organizados en carpetas independientes, desde `Problema01` hasta `Problema30`.

Cada carpeta contiene el código fuente del ejercicio, su archivo `README.md` con la explicación de la solución y una carpeta `evidencias` con la captura de la ejecución.

La solución general del proyecto se encuentra en el archivo `Condicionales.slnx`.

## Ejecución del proyecto

Para compilar todos los proyectos de la solución, ejecuta el siguiente comando desde la carpeta raíz:

```powershell
dotnet build Condicionales.slnx
```

Para ejecutar un ejercicio específico, entra en su carpeta y utiliza:

```powershell
dotnet run
```

## Repositorio

[Ver repositorio en GitHub](https://github.com/JeroHenaox/condicionales-csharp-jeronimo-henao)
